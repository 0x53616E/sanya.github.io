SanPlayer (SBP Editor)

Advanced BeatUp Chart Editor & Player

Release v0.4 WPF / C# .NET 4.8
Download Release Windows 32-bit Standalone

Download the portable .zip file. Extract it and run the executable. Ensure the assets folder remains in the same directory for the engine to load correctly.

Overview & Features

SanPlayer is a custom, feature-rich rhythm game player and chart editor. It is specifically designed to replicate and map BeatUp style charts (similar to Audition / CDIU) with absolute sub-pixel precision.

  • Live Split-View Charting: Edit your charts in real-time on the timeline while watching the Autoplay render your gameplay and hit-bursts instantly in the split-screen game view.
  • Editor Snapping: The timeline canvas supports precise note placement with dynamic snapping at 1/4 (Red), 1/8 (Blue), and 1/16 (Yellow) intervals.
  • Authentic Mechanics: Fully replicates 6-Key + Spacebar gameplay, including the iconic "Finish Move" (Lane 7) ease-out animations and combo gauge systems.
  • Chart Conversion & Formats: Directly import, edit, and convert between .slk (SYLK) and .ssc (StepMania) files. Save your full workspace logic instantly using native .san project files.
  • Anti-Flutter Rendering: Arrows glide with sub-pixel precision, ensuring a flawlessly smooth visual experience even during heavy mouse movement.

Project Structure & Assets

To run SanPlayer correctly, ensure the assets folder is placed in the output directory. You can swap backgrounds by simply dropping your images into the background folder.

SanPlayer/
├── SanPlayer.exe
├── assets/
│   ├── arrows/         # a18-a98 base arrows, l0-l5 glows, arrow_explode
│   ├── background/     # Drop custom .png/.jpg/.bmp backgrounds here
│   ├── bars/           # spacebar, blackbars, fn (Finish Move)
│   ├── game/           # Gameplay UI (combos, cups, gauges)
│   ├── sounds/         # beat.wav, space_bar.wav
