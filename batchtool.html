About the Software

Batch Toolkit Studio is a standalone desktop application built with a modern, glassmorphism-inspired UI. It provides professional-grade tools for manipulating textures, extracting frames, and organizing project directories without the need for complex external dependencies.

  • Smart Previews & Metadata: The interface dynamically adapts to your selected files. Animated GIFs are rendered as live, animated previews directly in the app, while other formats display detailed, comprehensive file metadata.
  • Lossless Image Conversion: Flawlessly convert PNG files to DirectDraw Surface (.dds) textures with full support for B8G8R8A8 Linear, BC3 (DXT5), and BC1 (DXT1) compression formats. Conversely, extract DDS textures back to standard PNGs with zero quality degradation.
  • GIF Frame Extraction: Instantly unpack animated GIFs into individual, high-quality PNG frames, neatly organized into automatically generated directories.
  • Mass Renaming: Keep massive asset libraries organized using an intelligent batch renaming utility that applies customizable, auto-incrementing naming patterns across your files.
