About This Engine

The BeatUp Engine is engineered for absolute precision, delivering an authentic rhythm game experience natively on modern Windows systems without the overhead of heavy commercial game engines.

🎯

1:1 Timing Engine

Beat detection ported directly from the original VB6 codebase. Perfect ±0.3, Great ±0.4, Cool ±0.5 windows.

🎹

Authentic Layout

Numpad 9/6/3 (Right), 7/4/1 (Left), Space, and Numpad 5 for Finish Moves. Includes Mirror & AutoPlay.

🎼

Chart Editor

Built-in timeline canvas with 1/4, 1/8, 1/16 snapping, and live split-view for real-time AutoPlay review.

🔊

miniaudio Engine

.ogg and .wav support with precise seekMs, adjustable playback speeds, and per-SFX volume control.

Installation Guide

  1. Extract the downloaded .zip file.
  2. Keep assets/ in the same folder as the .exe.
  3. Launch BeatUpEngine.exe.
  4. File → Import .ogg to load music.
  5. File → Import .slk to load the chart.

Asset Structure

Drop files into these folders to replace textures/sounds.

  • /arrows/ Sprites, lasers
  • /bars/ Lane backgrounds
  • /space/ Spacebar UI elements
  • /combo/ Combo & Score digits
  • /sounds/ beat.wav, miss.ogg, etc.
